# 功能说明与增强

本文档面向使用者：说明本版本在原项目之上提供了哪些功能、各部分怎么用。
安装与部署步骤见 [DOCKER.md](DOCKER.md)。

---

## 一、版本定位

原项目是一个本地运行的 Flask 单词学习应用：加词、AI 生成例句与记忆法、词汇知识图谱。
本版本保留全部原有能力，补上了「开箱即用、随身可用、有人带」这一层：

| 维度 | 原项目 | 本版本 |
| --- | --- | --- |
| 运行方式 | 本机装 Python 依赖后启动 | Docker 一条命令，也可在 VSCode 里 F5 调试 |
| 使用终端 | 桌面浏览器 | 桌面 + 手机（局域网 / 内网穿透），可加访问密码 |
| 学习闭环 | 抽词 → 看释义 → 标记 | 追加：每日学习记录、按天复习、手写笔记、AI 助教陪练 |
| AI 能力 | 造句、记忆法、知识图谱 | 追加：结合你的词表与学习进度答疑、出题、给复习建议 |
| 抽词 | 全库随机，仅排除上一个词 | 按轮发牌，一轮内不重复，跨设备/重启接续 |

## 二、新增功能

### 1. 一键部署

- **怎么用**：`docker compose up -d --build`，浏览器打开 `http://localhost:5000`
- **配置**：复制 `.env.example` 为 `.env`，填 `DEEPSEEK_API_KEY` 后 `docker compose up -d`
- **数据**：词库、学习记录、笔记都落在宿主机目录，重建容器不丢
- **附加**：`start-wordnest.ps1` 一键启动；`.vscode` 里有启动/重建/看日志/进容器四个任务；`.devcontainer` 支持 VSCode 直接进容器开发
- **说明**：没有 `.env` 也能启动，只是 AI 相关功能不可用

### 2. AI 四级冲刺助教（左侧栏）

- **入口**：任意页面左下角的「四级冲刺助教」面板；窄屏（手机）自动收起成圆钮，点开是底部浮层
- **能力**：围绕四级题型答疑（翻译、写作、阅读、语法辨析、易混词辨析、长难句），出小练习并讲解
- **上下文**：回答时会带上你的真实学习数据——词库规模、星标词、今天学过的词、最近在背的词、你写的笔记，因此建议是针对你本人的
- **快捷操作**：
  - 宽度可拖拽调整，双击标题栏复位
  - `↻ 同步` 把这段时间新学的词同步给 AI，不会丢当前对话
  - 下方「今天学的 / 星标词」标签点一下复制单词，双击填入输入框
- **使用条件**：需要配置 API Key

### 3. 每日学习记录

- **入口**：首页右上角「学习记录」，或词表页工具栏
- **看到什么**：每天学了哪些词、各复习了几次、最近 30 天的柱状图
- **怎么用**：点某一天的「复习这天的单词」，之后抽词只从那天的词里出，一轮内不重复；右上角可退出复习模式
- **记录时机**：查看释义、标记星标都会计入当天

### 4. 学习笔记

- **入口**：首页右上角「我的笔记」、单词卡上的笔记图标（会**自动关联当前单词**）、词表页工具栏
- **能力**：多条笔记并存，可填标题、关联单词、标签；左侧列表按更新时间排序，支持全文搜索
- **和 AI 的关系**：AI 助教每次回答会读取你最近 8 条笔记作为参考，所以把易错点、老师讲的规律记进去，问问题时它就知道
- **快捷键**：`Ctrl+S` 保存

### 5. 词库导入与批量补全

- **导入**：`python import_vocabulary.py --csv 词表.csv`
  - 默认导入 `words` 词表；`--list cet4` 可新建独立词表，不影响原有数据
  - 目标词表已有词时会拒绝覆盖，确需覆盖加 `--replace`（自动备份到 `backup/`）
  - 表头按列名识别，最少需要「单词」和「释义」两列；音标会写进笔记字段展示
  - 仓库附带 `vocabulary.sample.csv`（20 个四级词）可直接试用
- **批量补全**：`python enrich_words.py --limit 10 --dry-run` 先预览，`--limit 0` 补全部
  - 只补「例句」和「记忆法」两个字段，不覆盖你原有的词性和释义
  - 已补过的词自动跳过，支持中断后继续
- **没有 Python 环境**时，可用容器执行（命令见 DOCKER.md）

### 6. 按轮抽词与本轮进度

- **行为**：把当前词库洗成一副牌依次发，**一轮内每个词只出现一次**；发完自动开启新一轮并重新洗牌，新一轮第一张不会等于上一轮最后一张
- **词库变化**：中途新增的词本轮就会出现，删除的词自然消失，不会错位
- **多端一致**：轮次状态存在服务端，手机和电脑接力同一轮，重启容器也不重置
- **进度显示**：自测页底部「本轮 37 / 400」，悬停显示第几轮、还剩多少
- **独立计数**：全部单词、只看星标、复习某一天，各自有独立的轮次

### 7. 访问密码（可选）

- 在 `.env` 里设置 `WORDNEST_PASSWORD=你的密码` 后重启容器，所有页面需先登录
- 未登录访问接口返回 401，AI 侧栏会给出对应提示
- 不设置则与原项目一致，无需登录

### 8. 手机与远程访问

- **局域网**：`http://电脑IP:5000`，手机与电脑同一 WiFi 即可
- **外网**：`start-tunnel.ps1` 启动 Cloudflare 快速隧道，得到一个临时 HTTPS 地址
- **建议**：公网可访问时务必设置访问密码；手机可「添加到主屏幕」当 App 用
- **界面**：窄屏下 AI 面板收起、单词与图标改上下排列，长单词不会压住按钮

## 三、优化与修复

以下均为可感知的改进，不涉及用法变化：

| 项目 | 原项目表现 | 本版本 |
| --- | --- | --- |
| 启动 | 缺少 `requests` 依赖，直接报 `ModuleNotFoundError` | 依赖补全，开箱即起 |
| 朗读 | 音频标注为 MPEG，部分浏览器无声音 | 正确标注 WAV，各浏览器均可播放 |
| 切换词表 | 会连带清空聊天/学习记录的数据库连接，切换后可能报错 | 只切换词库连接，其他功能不受影响 |
| 抽词重复 | 400 词池中 20 次抽取约 39% 概率出现重复 | 一轮内不重复（详见功能 6） |
| 切词速度 | 约 450 ms，界面会闪「加载中」 | 约 30 ms，切词无闪烁 |
| 列表页体积 | 未压缩约 540 KB | gzip 后约 100 KB，手机加载明显更快 |
| AI 出网 | 开启代理后容器内报 SSL 错误 | 自动尝试代理与直连，两种网络环境都能用 |
| 键盘快捷键 | 空格、方向键有全局响应，输入文字时误触 | 已移除，避免打字时释义闪动 |
| 数据库 | 所有数据混在少数几个库中 | 按用途分离，抽词状态独立存放，性能与安全兼顾 |

## 五、数据与升级

| 目录 | 内容 | 可否删除 |
| --- | --- | --- |
| `instance/` | 词库（每个词表一个 `.db`） | 不可 |
| `study_data/study.db` | 学习记录、笔记 | 不可 |
| `study_data/cycle.db` | 本轮抽词状态 | 可以，删后重新开一轮 |
| `chat_data/` | AI 对话记录 | 可以 |
| `settings.json` | 界面偏好 | 可以 |

- **备份**：复制 `instance/`、`study_data/`、`chat_data/` 三个目录即可
- **升级**：替换代码后 `docker compose up -d --build`，数据目录不动
- **从原项目迁移**：原项目的数据目录结构与字段兼容，把原 `instance/` 复制过来即可继续使用
